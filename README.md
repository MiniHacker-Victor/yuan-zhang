# 元账 · 留学生多币种记账

为留学生在海外学习和生活设计的本地优先记账 PWA，适合同时管理本地开销与家乡货币。你可以自行选择常用的默认记账币种，也能为每笔账单单独切换币种；英镑、人民币、美元、港币、欧元和日元均可使用。统计和预算统一折算为英镑，方便持续查看消费情况。

## 功能

- 默认记账币种可在“设置 → 默认选项”中自行选择：GBP、CNY、USD、HKD、EUR 或 JPY；每笔账单也可单独选择币种。
- 统计和预算以英镑为基准；每笔外币账单保存录入时汇率，后续汇率变化不会改写历史金额。
- 自动从 Frankfurter 获取免密钥参考汇率，也支持手动覆盖和离线缓存。
- 支持总预算和分类预算，预算按生效周期保留历史版本。
- 自然周、自然月、自然年汇总，以及分类占比、趋势和环比分析。
- 总览可在六种币种之间切换显示，非英镑结果按最新汇率估算。
- 规则化消费建议，包括超预算、消费速度过快、分类超支和趋势变化。
- IndexedDB 本地存储、JSON 备份恢复、CSV 明细导出和可安装 PWA。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

## 检查

```bash
npm test
npm run test:e2e
```

端到端测试使用 Playwright 的 Chromium，并同时覆盖桌面和手机视口。

## 数据说明

账单和设置只保存在当前浏览器的 IndexedDB 中，不会上传服务器。浏览器数据被清理或设备损坏时本地账本无法自动恢复，建议定期在“设置”页导出 JSON 完整备份。外币汇率来自公开参考数据，仅用于个人记账展示。
